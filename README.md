# 📘 Furdiz 소개
**Furdiz**는 조건 기반 필터링을 통해 보호동물과 임시보호자를 빠르게 매칭하는 플랫폼입니다. 사용자 선호 조건과 보호동물 특성을 다중 조건 기반으로 분석하고, 점수화 알고리즘을 통해 최적의 임시보호 매칭 로직을 설계하여 기존 단순 조회형 임시보호 플랫폼과 차별화합니다.

지금 **Furdiz**로 함께 간단한 모임을 즐겨보세요!

<br/>

## ⭐️ 주요 기능

### 1. 임시보호 조건에 맞는 동물 필터링하기
사용자 조건 대비 태그 일치율(일치 조건 수 / 전체 선택 조건 수) 기반 적합도 점수 산출 로직 구현<br/>
조건별 가중치(Weight)와 일치율(Match Rate)을 조합한 매칭 점수 계산 알고리즘 설계

<br/>

### 2. 임시보호 기록하기
임시보호 과정에서 발생하는 건강 상태, 식사 기록, 산책 여부, 특이 행동 등<br/>
다양한 정보를 체계적으로 작성·관리하고 손쉽게 공유할 수 있는 기록 시스템 제공
